# Green DevOps Research Website

Static academic-purpose information website for SLIIT project R26-SE-027, "Green DevOps - Energy Efficient CI/CD Pipeline."

## Structure

- `index.html` - Home
- `domain.html` - Research domain, methodology, components, evaluation, references
- `milestones.html` - Proposal, PP1, PP2, final/journal stage, assessment placeholders
- `documents.html` - Academic document archive
- `presentations.html` - Presentation archive and extracted transcripts
- `about.html` - Team and component contributions
- `contact.html` - Academic contact layout
- `css/style.css` - Shared responsive styling
- `js/main.js` - Minimal mobile navigation behavior

Large original slide decks were reviewed but not copied into the deployable site because the course hosting guideline limits the site to about 20 MB. Lightweight transcripts are included in `assets/presentations/`.

Selected source diagrams, including the PP2 high-level architecture, are optimized as WebP assets under `assets/diagrams/`.
