Research overview

An integrated sustainability view across DevOps stages

The research studies how carbon-aware decision-making can support Release, Deployment, Operation and Monitoring as one connected lifecycle, instead of optimizing each stage in isolation.

Problem and motivation

Conventional CI/CD and cloud-native operations prioritize speed, automation and reliability. They often rebuild or test more than needed, deploy without considering grid carbon intensity, scale reactively, and monitor performance without a sustainability baseline.

Research gap

Existing Green DevOps work commonly addresses selective testing, carbon scheduling, resource prediction or monitoring separately. This project focuses on the missing integration layer that connects sustainability decisions across the whole delivery lifecycle.

Research objective

Develop an integrated Green DevOps framework that embeds carbon-aware decision support across Release, Deployment, Operation and Monitoring while preserving delivery velocity, reliability, application performance and SLA-related requirements.

Research components

Four components, one feedback loop

Release

Git-diff-based change-impact analysis selects affected Maven modules, reduces unnecessary build/test execution and uses LightGBM carbon-intensity classification for timing decisions.

Deployment

Deployment telemetry and grid carbon intensity support carbon-aware scheduling and AI-assisted strategy decisions across Recreate, Rolling and Canary deployment options. Validation included confidence calibration, reason-quality judging, a 5% deterministic fallback A/B route and historical strategy win-rate lookup.

Operation

An LSTM workload model, carbon estimation and job-priority logic support proactive Kubernetes runtime recommendations such as scale, maintain or delay eligible work.

Monitoring

Historical sustainability records, Z-score analysis, Isolation Forest-based anomaly detection and a Sustainability Health Score provide feedback to earlier stages.

Final framework title

The revised journal manuscript presents the final academic title as "An Integrated Green DevOps Framework for Sustainable Software Delivery and Operations."

Website scope

This website explains and documents the research. It is not a Kubernetes dashboard, CI/CD execution console, monitoring tool or live implementation of the research system.
